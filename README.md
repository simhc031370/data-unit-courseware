# 데이터실 — 중학교 정보 데이터 단원 코스웨어

2022 개정 중학교 정보 **(2) 데이터** 영역을 수업용으로 구성한 실시간 코스웨어입니다.  
성취기준 문장을 암기시키는 구성이 아니라, 기준이 요구하는 **개념·기능·문제 해결**을 가르칩니다.

## 학습 내용 (성취기준에서 분해)

| 파트 | 가르치는 내용 | 설계 근거 |
| --- | --- | --- |
| 디지털로 표현되는 데이터 | 아날로그/디지털, 문자·이미지·소리·영상 개요 | 9정02-01 |
| 진법 변환 | 10진·2진·16진 변환 절차 + 실전 문제 | 9정02-01 |
| 문자 코드 변환 | ASCII 코드 변환 과정 + 실전 문제 | 9정02-01 |
| 이미지의 디지털 표현 | 픽셀·RGB·해상도·색 깊이 + 실전 문제 | 9정02-01 |
| 필요한 데이터 모으고 관리하기 | 목적 기반 수집, 방법, 표본, 분류·저장, 책임 | 9정02-02 |
| 표와 그림으로 구조화하기 | 표, 다이어그램, 기본 그래프 | 9정02-03 |
| 관계 읽고 의미 해석하기 | 관계, 대표값, 시각화 함정, 근거 있는 주장 | 9정02-04 |
| 데이터로 융합 문제 해결하기 | 타 분야 문제 + 프로젝트 전 과정 | 9정02-05 |

성취기준 원문·내용 요소는 각 파트 하단 **교사 참고**에만 접어 두었습니다.

## 기능

- 이론 · YouTube 영상 · 활동 · 형성평가
- 형성평가 결과 → 보충 / 심화 자료
- 교사: 접속·학습 위치 실시간 확인, 집중하기(화면 공유+이동 잠금)
- 학생: 손들기

## 실행

```bash
npm install
npm run dev
```

`http://localhost:3000`

## 배포 (Vercel)

- 실시간 교실 기능은 Vercel용 **API 폴링**으로 동작합니다 (`/api/room`).
- 로컬에서 예전 Socket.IO 서버를 쓰려면 `npm run dev:socket` (선택).

```bash
npm i -g vercel
vercel
```
